# Company OS

Este repositório é o sistema operacional de conhecimento da empresa: onde vivem as regras, decisões, processos e projetos que orientam humanos e agentes de IA no dia a dia.

## Por onde começar

Leia primeiro [`00-foundation/documentation-framework.md`](./00-foundation/documentation-framework.md) — define como todo documento da empresa deve ser escrito, estruturado e mantido. Todas as demais áreas seguem essas regras.
