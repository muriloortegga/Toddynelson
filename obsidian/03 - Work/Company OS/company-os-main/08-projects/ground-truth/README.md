# Ground Truth

> Primeira operação de campo do Company OS: coletar evidência real de mercado, via entrevista direta com centenas de profissionais de Fitness & Wellness, para testar no mundo real o que o Discovery (documentado em `01-product/`) levantou a partir de fontes secundárias.

## Por que essa operação existe

Todo o trabalho em `01-product/` — mapeamento de mercado, dores, padrões de problema, priorização e validação da hipótese principal — foi construído com evidência pública secundária (reviews, imprensa, associações de classe). É uma base sólida para gerar hipóteses, mas nenhuma dessas fontes é uma conversa direta com um profissional do nosso mercado-alvo. **Ground Truth existe para fechar essa lacuna**: transformar hipótese em evidência de primeira mão, coletada de forma sistemática, repetível e auditável — não uma rodada informal de conversas.

Esta operação não testa produto. Ela testa se as pessoas, as dores e os padrões que documentamos existem da forma como acreditamos que existem.

## Como este projeto se conecta ao resto do Company OS

- **Entrada:** os seis atores, as dores, os sete Problem Patterns e a priorização em `01-product/` são o roteiro do que testar em campo — cada pergunta do roteiro de entrevista (documento 6) foi desenhada para checar um item específico dessas evidências, não para validar uma solução.
- **Saída:** o Banco de Insights (documento 9) é o novo ativo que esta operação produz. Ele deve, ao final, permitir revisar `01-product/problem-patterns-fitness-wellness.md`, `01-product/priority-opportunities.md` e `01-product/thesis-validation.md` com evidência de primeira mão — confirmando, revisando ou descartando o que foi levantado por fontes secundárias.
- **Regra dura da operação:** nenhum documento aqui assume, sugere ou nomeia uma solução, produto, funcionalidade, SaaS, uso de IA ou modelo de monetização. Esta operação estuda pessoas, não valida produto.
